# Хронометр — учёт рабочего времени

Веб-приложение (PWA) в духе Clockify: таймер в одно касание, ручные записи, проекты, клиенты и теги,
календарь недели, отчёты за любой период с выгрузкой в PDF и CSV, синхронизация через Google Диск.

Откройте приложение по ссылке и нажмите «Установить приложение» в браузере — оно появится
на рабочем столе телефона или компьютера и будет работать без интернета.

Данные хранятся в браузере на устройстве. При входе через Google копия сохраняется в скрытой
папке приложения на вашем Google Диске — другие пользователи и владелец приложения её не видят.

## Жесты

- Разделы на телефоне листаются свайпом по экрану.
- Запись в журнале: свайп вправо — продолжить (запустить таймер с тем же описанием и проектом),
  свайп влево — удалить, в подсказке внизу можно отменить.
- Горячие клавиши на ПК: `S` — старт/стоп, `N` — добавить запись вручную.

## Устройство

Каркас взят из [Монетки](https://github.com/palyonoviw-coder/monetka): тот же стек без сборки,
дизайн и темы (`styles.css`), иконки, Service Worker, модальные окна и модуль синхронизации `sync.js`
(слияние по записям, «надгробия» для удалённых).

| Файл | Что внутри |
| --- | --- |
| `app.js` | данные, разделы (Таймер, Календарь, Отчёты, Проекты, Ещё), свайп записей, экспорт PDF/CSV |
| `sync.js` | синхронизация с Google Диском (из Монетки, свои коллекции и имя файла) |
| `config.js` | OAuth Client ID Google |
| `sw.js` | офлайн-кэш |
| `vendor/` | Swiper, pdfmake со шрифтом Roboto (кириллица в PDF) |

Локальный запуск: `python -m http.server 8765` в папке проекта, затем http://localhost:8765.

Иконки: [Lucide](https://lucide.dev) (ISC). Перелистывание разделов: [Swiper](https://swiperjs.com) (MIT).
PDF: [pdfmake](https://pdfmake.github.io) (MIT), шрифт Roboto (Apache 2.0). Файлы в `vendor/`.
